# Technical Writing & Document Control Samples

This folder contains examples of technical documentation and document control practices, demonstrating how engineering and manufacturing documents are created, reviewed, approved, distributed, revised, and retained.

## Sample 1: Standard Operating Procedure (SOP)

**SOP-DOC-001: Control of Engineering and Manufacturing Documents**

A procedural guide covering the document lifecycle, including:

- Document creation and identification
- Technical review and approval
- Controlled release and distribution
- Revision and change management
- Obsolete document handling and archival
- Records, traceability, and compliance

[View SOP-DOC-001 (PDF)](SOP_Control_of_Engineering_Documents.pdf)
